# Security

Please report security problems in Full Self Browsing, its MCP server or this plugin privately, not in a public issue.

Use GitHub private vulnerability reporting on the FSB repository: open https://github.com/fullselfbrowsing/FSB/security/advisories/new and describe the problem, the affected versions and the steps to reproduce it.

For general questions and non-security bugs, use https://github.com/fullselfbrowsing/FSB/issues.
