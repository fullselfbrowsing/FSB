Brackets the top of every site page. 64px tall, blurred translucent surface, hairline bottom edge.

```jsx
<NavBar
  active="Home"
  links={[{ label: 'Home', href: '/' }, { label: 'About', href: '/about' }, { label: 'Agents', href: '/agents' }]}
/>
```

The active link carries a 2px orange underline 4px below the baseline. Below 768px the link row and action hide behind a hamburger.
