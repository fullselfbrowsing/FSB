The FSB wordmark — use it anywhere the brand signs a surface: nav bars, footers, onboarding headers, hero headlines.

```jsx
<FsbMark size="1.5rem" />
<FsbMark size="1.32rem" version="▽X.Y.Z" />
```

The mark inherits `currentColor`, so it reads correctly on both themes with no props. Nav uses `1.5rem`, footer `1.32rem`, hero headlines `1em` (inherits the heading size). Never recolor the F, S and B separately, never equalize their weights, never stretch the lockup — the weight contrast is the identity.
