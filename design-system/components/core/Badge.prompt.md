Pills carry status, category and technical labels. Pick the variant by meaning, not by color.

```jsx
<Badge variant="eyebrow" icon={<i className="fa-solid fa-bolt" />}>Native API handlers</Badge>
<Badge variant="fsb" icon={<i className="fa-solid fa-code" />}>DOM-Based</Badge>
<Badge variant="nav" meta="/issues">Linear</Badge>
<Badge variant="tool">scroll_to</Badge>
```

Round pills (`eyebrow`, `nav`) sit at 999px; square tags (`fsb`, `competitor`, `recommended`) at 10px; mono chips (`selector`, `tool`) at 4–8px. Mono variants are marked `translate="no"`.
