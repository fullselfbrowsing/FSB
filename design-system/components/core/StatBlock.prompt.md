Numbers that back a claim. Sits inside a `highlight` Card or under a hero.

```jsx
<StatBlock stats={[
  { value: '50-200ms', label: 'per step' },
  { value: '~$0.03', label: 'per 100 steps' },
]} />
```

Values are mono-flavored and marked `translate="no"`. Two or three stats; more reads as a table.
