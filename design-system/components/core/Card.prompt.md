Cards for capabilities, model providers and comparisons.

```jsx
<Card icon={<i className="fa-solid fa-bolt" />} title="Direct API Execution">
  Calls an app's own authenticated API through your session.
</Card>

<Card variant="provider" recommended icon={<i className="fa-solid fa-bolt" />} title="xAI Grok">
  Grok 4.1 Fast, Grok 4
</Card>
```

Feature cards go two-up, provider cards three-up, competitor cards in a dimmed grid beside a single `highlight`. Only one card in a comparison gets `highlight` or `recommended`.
