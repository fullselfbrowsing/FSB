<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Exact source selection/certificates → graph snapshot | A subset, duplicate, stale generation, incomplete proof, foreign endpoint, cap prefix, or cache from another exact set could be mistaken for complete evidence. |
| Graph records/labels → typed truth | Phase 55 labels and candidate relations are valid graph data but are not typed facts, execution proof, amendment scope, or governing precedence. |
| Source excerpts → configured provider | Contract prompt injection may request tools, cross-document comparison, IDs, URLs, confidence, governance, arithmetic, or expanded data access. |
| Provider response → normalized candidates | Malformed/hostile JSON, unknown handles, clipped locators, stale settings, cancellation, and raw-response retention could influence later durable truth. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T56-05 | Spoofing / Tampering | exact-set graph snapshot | mitigate in Tasks 1-2 | Exact unique set, complete proof, source-state/fingerprint/generation checks, whole-result caps, deterministic sort/digest, before/after live-cache checks, and zero partial output. |
| T56-02 | Tampering | graph candidate/label interpretation | mitigate in Tasks 1-4 | Snapshot keeps candidate markers explicit; extractor receives handles and source bytes but never converts graph labels or ordering into legal conclusions; invariant tests rename/reorder labels. |
| T56-01 | Elevation of privilege / Tampering | truth extractor | mitigate in Tasks 3-4 | Static inert prompt, exact candidate schema, issued registries, no tool/expression/ID/URL/governing/confidence fields, whole-batch rejection, and no repair for semantic/evidence failures. |
| T56-03 | Spoofing | evidence handle/locator admission | mitigate in Tasks 3-4 | Resolve exact source/fragment/record/relation/locator/range against the snapshot and current source bytes; reject stale, foreign, clipped, duplicate, or forged references. |
| T56-08 | Information disclosure | provider/raw lifetime | mitigate in Tasks 3-4 | One-source bounded excerpts, configured provider only, caller signal, raw response cleared in `finally`, category-only repair/diagnostics, no durable write capability. |
</threat_model>
