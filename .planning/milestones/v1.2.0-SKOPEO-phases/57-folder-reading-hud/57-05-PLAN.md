## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host document → Shadow shell | Hostile DOM, CSS, labels, focus behavior, and layout surround the isolated HUD. |
| Contract model → DOM | Bounded but untrusted display strings and opaque action IDs become interactive UI. |
| Human/live evidence → planning artifacts | Private authorized corpus behavior is summarized without exposing corpus identifiers or content. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-57-01 | Spoofing | Shell model/action | mitigate | Closed model validation and current opaque action IDs reject arbitrary renderer modes and actions. |
| T-57-02 | Tampering | HUD state updates | mitigate | Stable keys plus runtime currentness and synchronous replacement prevent stale DOM from becoming current. |
| T-57-03 | Information Disclosure | Rendered DOM/UAT | mitigate | `textContent`, forbidden-field tests, no links/URLs/IDs/page text, and sanitized human evidence prevent leakage. |
| T-57-04 | Elevation of Privilege | Citation button | mitigate | A real button passes only `actionId` to the current callback; all navigation authority remains in background. |
| T-57-05 | Repudiation | Eval/UAT status | mitigate | Separate deterministic/provisional/human result fields and `live_approved: false` prevent synthetic evidence from masquerading as approval. |
| T-57-06 | Denial of Service | Rail rendering | mitigate | Hard collection/string caps, bounded height, local paging, timer cleanup, and no host observers bound rendering work. |
| T-57-07 | Tampering | Host CSS/layout | mitigate | Existing Shadow root isolation, tokenized styles, forced-colors rules, and no host writes prevent mutual interference. |
| T-57-08 | Tampering | Teardown/focus | mitigate | Central shell lifecycle removes nodes/listeners/timers/actions and conditionally restores focus, with zero-residue assertions. |
| T-57-SC | Tampering | npm/pip/cargo installs | mitigate | No install occurs; package scripts only reference repository tests and dependency/lockfile changes are forbidden. |
</threat_model>
