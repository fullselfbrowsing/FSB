<interfaces>
Create frozen global/CommonJS factory `FsbSkopeoAskEngine.create(options)`. Dependencies are exact and injected: ask schema, configured provider factory/settings reader, nonce/handle factory, byte length, and clock only for bounded provider timeout—not civil/policy decisions. The engine never reads Chrome, storage, Drive, DOM, or global private facades directly.

`prepare(input, operationSignal)` consumes an already-authorized exact immutable request: safe question, exact scope/digests, complete flag, bounded certified excerpts, current truth evidence/citations/conflicts, and a no-storage acknowledgement callback. It creates an in-memory evidence registry with opaque handles.

`answer(session, operationSignal)` performs one configured provider call and returns either a schema-parsed current cited answer or a closed status. `discard(session)` zeroes excerpt/provider/candidate influence. There is no conversation/follow-up history API.
</interfaces>
</context>
