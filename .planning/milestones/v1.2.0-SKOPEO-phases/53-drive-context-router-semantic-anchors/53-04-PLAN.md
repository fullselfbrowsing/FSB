<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Worker/tab events → content runtime | Sender/tab/generation and update type determine whether an existing session reroutes or terminally dies. |
| Trusted isolated adapter → router/registry | Functions/DOM roots never cross page/runtime messages and must remain bounded to the live generation. |
| Router/registry callbacks → shell | Full authority tuple is checked again immediately before visible side effects. |
| Runtime teardown → worker certificate | Cleanup is evidence only after router/registry/shell/listeners/globals are actually gone at exact zero. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-53-04-01 | Spoofing | route-change/runtime messages | mitigate | Chrome sender ID, current tab record, positive generation, exact keys, exact origin parsing downstream. |
| T-53-04-02 | Tampering | reversed async route/bind completion | mitigate | Generation/context/identity/binding checks after every await and at shell callback; deterministic reversal tests. |
| T-53-04-03 | Elevation of privilege | same-document update as auto invocation | mitigate | Route handoff only for ACTIVE records; no executeScript/BEGIN/prepare/commit on URL-only updates. |
| T-53-04-04 | Denial of service | duplicate observers/modules/listeners | mitigate | Exact once-only injection, one generation owner, narrow adapter root, one registry, resource ledger and idempotent teardown. |
| T-53-04-05 | Information disclosure | worker/storage messages | mitigate | No semantic IDs/page strings/adapter functions in worker messages or persisted lifecycle records. |
| T-53-04-06 | Tampering | teardown resurrection | mitigate | Terminal then abort, registry/router dispose, shell destroy, listener/global removal, exact certificate, stale saved-reference tests. |
</threat_model>
