<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Authorized exact source set → query scope | A forged/cloned scope can broaden reads to another source, account, corpus, or generation. |
| Fresh exact scope → durable shards → in-memory cache | Boot-time or stale/corrupt shard hydration without current authority can reveal or retain another source/generation. |
| Query input → traversal/search | Deep/cyclic graphs, large strings, result floods, or dynamic expressions can block the worker or bypass the closed surface. |
| Query output → trusted consumer | Raw records, storage keys, source text, or uncertified source existence can escape through projections. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T55-02 | Spoofing / Information disclosure | query scopes and partition caches | mitigate | WeakMap identity, exact source-generation set, key/value ownership reparse, no global fallback, cross-partition/source fixtures, and target-only advance/revocation fixtures that suppress the old candidate overlay before cache/query influence. |
| T55-05 | Tampering | source replacement/cache invalidation | mitigate | Store cache-owner purge removes source contributions before absence proof; lazy hydration occurs only after exact authority, and queries compare every hit/edge/candidate endpoint to active generation pointers. |
| T55-08 | Denial of service / Information disclosure | lexical/traversal/provenance facade | mitigate | Exact input schemas, depth/node/edge/result/byte caps, iterative visited-set traversal, and location-aware marker tests permit a validated name-bearing label only in exact-owned lexical cache and freshly authorized bounded projections while rejecting it from diagnostics/errors/unrelated or closed output. |
| T55-09 | Elevation of privilege | query language/runtime surface | mitigate | No JMESPath/dynamic evaluation/embedding/MCP/server dependency; static/runtime tests enumerate the exact four methods. |
| T55-SC | Tampering | dependency surface | mitigate | Reuse checked-in MiniSearch and native JavaScript only; package metadata is unchanged. |
</threat_model>
