<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Parsed graph records → multi-key local storage | A failed write can leave visible partial payload or inconsistent source/index generations. |
| Corpus mutation lane → graph-owned keys/caches | A raw foreign guard, forged/cloned capability, wrong participant/mode/request, or replay can delete or retain the wrong source influence. |
| Durable bytes → fresh MV3 worker | Corrupt manifests, journals, pages, or shard references can resurrect stale or cross-partition state. |
| Provider/error metadata → diagnostic ledger | Confidential source or response values can leak through logs, validator output, or storage diagnostics. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T55-02 | Spoofing / Information disclosure | graph keys, candidate links, and active pointers | mitigate | Reparse authoritative key/value ownership tuples and active generations on every read; exact partition/source tests reject substitutions; candidate relation/overlay IDs bind both current endpoint versions/generations and proposing-source evidence; proposer-only empty replacement performs no target read or existence-dependent response. |
| T55-05 | Tampering / Repudiation | replacement/purge state machine and participant bridge | mitigate | Close pointers first, journal every purge/absence/stage step, require corpus-owned one-call capabilities plus all four real participant proofs, and publish the sole active pointer last. |
| T55-06 | Denial of service / Tampering | quota, corruption, MV3 recovery | mitigate | Bound values/pages/steps, discard invalid staging, rebuild derivable shards, leave source withheld, and prove sibling records byte-identical after every injected failure. |
| T55-08 | Information disclosure | diagnostics and store readers | mitigate | Location-aware scans allow IDs/fingerprints only in parsed authoritative ownership records and valid name-bearing derived labels only in authoritative record labels/matching source-owned lexical shards; closed diagnostics/errors, unrelated partitions, and other non-authoritative bytes exclude them as well as raw text, filenames, raw output, credentials, and URLs. |
| T55-SC | Tampering | dependency surface | mitigate | No new package, database, IndexedDB owner, remote service, or dynamic evaluator is introduced. |
</threat_model>
