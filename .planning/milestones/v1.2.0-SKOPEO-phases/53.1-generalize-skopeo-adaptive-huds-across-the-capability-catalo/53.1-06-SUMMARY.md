## Decisions Made

- Pair a verified semantic label with its stable `{kind:id}` identity in target copy so a visible label alone is never mistaken for target authority.
- When no semantic entity exists, preserve descriptor property order and admit only exact normalized target-role field names/suffixes. Duplicate normalized roles, secret target roles, control characters, missing roles, or over-bound composite copy return `target-unrepresentable` without minting a token.
- Treat unsupported schema constraints and any projection/descriptor param-summary or side-effect disagreement as fail-closed classification inconsistency rather than partially validating args.
- Mask secret material values as `Hidden`, keep them out of serialized confirmation models, and require all other target/material values to fit the UI bounds without truncating consequential copy.
- Consume the token and enter `pending` before calling the router. A concurrent/repeated confirmation sees no open token, while the first attempt can return only if the full tuple and canonical classification still match after await.
