<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Explicit background generation → injected runtime | Configure/projection must be exact, current, and accepted before any shell preparation. |
| Runtime context/render/action work → page side effects | Every visual/action effect repeats final tuple authority and terminal-state checks. |
| Content read/consequence messages → background router | Sender tab metadata and the current background controller/projection/gate manager are authoritative; content tuples and slugs are claims to revalidate. |
| Automated fixture/browser evidence → release claim | Fixtures and local Chrome mechanics cannot imply live third-party-host approval. |

## STRIDE Threat Register

| Threat ID | Severity | Category | Component | Disposition | Mitigation Plan | Automated negative proof |
|-----------|----------|----------|-----------|-------------|-----------------|--------------------------|

| T-53.1-08 | High | Information disclosure | cross-tab/profile projection | mitigate | Derive content tab from sender, key controller/projection/gate by tab+generation+origin+versions, and reproject on MV3 wake before reauthorizing. | Catalog runtime tests recycle tab IDs, change origins/profile versions, simulate worker loss, and prove no foreign capability/result leakage. |
