## Decisions Made

- Keep display copy executable only as reviewed bundled metadata. Installed schema titles/descriptions, semantic entities, parameter-name patterns, page nouns, and action labels cannot create or alter a consequence target.
- Bind both the complete installed schema digest and canonical compiled consequence digest. A changed hidden schema constraint, role, label, bound, accepted/excluded set, or rendered field makes the old confirmation stale.
- Treat Notion's `notion.so` catalog service and `app.notion.com` live page/execution origin as different authorities. Compare descriptor service to generated full service, and separately require the installed execution origin to match the current exact page origin.
- Count a field represented only from concrete target/material rows. The materializer's reported field array is checked against rows, then the gate independently compares that derived set with validated supplied own keys.
- Keep open optional Notion `properties` objects uncollectable. The generic object path requires an explicit `bounded-object` role and a closed, bounded scalar-leaf schema.
