## Sampling Rate

- **After every task commit:** Run the focused owning test plus `node --check` for each changed classic-script JavaScript file.
- **After profile/schema changes:** Run `node tests/skopeo-profile-schema.test.js && node tests/skopeo-profile-coverage.test.js`.
- **After context/composition changes:** Run `node tests/skopeo-adaptive-composer.test.js` plus affected existing shell/anchor tests.
- **After readiness/execution changes:** Run `node tests/skopeo-capability-projection.test.js && node tests/skopeo-consequence-gate.test.js` plus affected capability-router, consent, audit, classification, and denylist tests.
- **After lifecycle/injection changes:** Run `node tests/skopeo-catalog-runtime.test.js` plus the existing session-lifecycle and injection-completeness contracts.
- **After every plan:** Run the complete Phase 53.1 focused chain.
- **After every plan wave:** Run the focused chain plus `npm run validate:extension`.
- **Before `$gsd-verify-work`:** Run the focused chain, representative real-Chrome contract, `npm run validate:extension`, and `npm test`; preserve live third-party-host evidence separately as `human_needed` until recorded.
- **Max automated feedback latency:** 15 seconds for task-level pure contracts and 60 seconds for the focused phase chain, excluding real Chrome and the full repository suite.
