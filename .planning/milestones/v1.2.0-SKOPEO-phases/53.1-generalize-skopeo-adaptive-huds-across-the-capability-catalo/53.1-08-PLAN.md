Plan 08 establishes these exact additive interfaces for downstream gap plans:

```text
FsbSkopeoActionAuthority.canonicalSchemaJson(schema) -> canonical JSON string or null
FsbSkopeoActionAuthority.schemaDigest(schema) -> Promise resolving to `sha256:` plus 64 lowercase hex characters, or null
FsbSkopeoActionAuthority.normalizeResolvedAuthority(resolved) ->
  { tier, executionOrigin, sideEffectClass, paramSchema, schemaDigest } or null
FsbSkopeoActionAuthority.authorityMatches(expected, actual) -> boolean

FsbCapabilityRouter.getResolvedParamsSchema(resolvedEntry) -> full schema or null
FsbCapabilityRouter.validateResolvedArgs(resolvedEntry, args) -> boolean

buildInstalledResolver(catalog) -> installed capability-catalog resolve function
```

Generated/background-only capability authority:

```text
executionAuthority: {
  tier: "T1a",
  executionOrigin: "https://app.notion.com",
  sideEffectClass: "read" | "write" | "destructive",
  paramSchema: COMPLETE_CANONICAL_HANDLER_SCHEMA,
  schemaDigest: "sha256:..."
}
```

Projected/content capability binding:

```text
executionOrigin: "https://app.notion.com"
schemaDigest: "sha256:..."
paramSummary: {
  count: FULL_PROPERTY_COUNT,
  required: BOUNDED_SHOWN_REQUIRED_NAMES,
  optional: BOUNDED_SHOWN_OPTIONAL_NAMES,
  truncated: true | false
}
```

`paramSchema` is forbidden in the content projection. `paramSummary` is display copy only and is never an authorization or router-validation input.
