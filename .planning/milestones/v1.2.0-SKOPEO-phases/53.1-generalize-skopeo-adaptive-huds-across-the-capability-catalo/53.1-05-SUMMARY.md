## Decisions Made

- Treat the schema arrays as the sole adapter/renderer namespace and copy them into frozen exported arrays; profile data never selects a function outside those exact IDs.
- Treat visible labels only as bounded display copy after exact-origin and stable opaque identity are already proven. Path, heading, selector, class, DOM-shape, and position evidence cannot create an anchor.
- Return `null` for generic or ordinary missing-evidence cases so the Plan 03 resolver produces its recognized app-level `no-stable-entity` result rather than an error-looking guessed entity.
- Filter Drive/Docs evidence to the existing router's five stable signals, call that router exactly once, preserve its identity/evidence, and pass uncertain or unsupported results through without a local fallback.
- Require exact data-only success/error result schemas before rendering. Hostile scalar values are normalized to bounded text, unsupported genre structures are dropped, and malformed results use the approved action-name and safe-recovery notice grammar; outputs are always recursively frozen.
