<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Asynchronous tab/status response to side-panel DOM | A response may belong to a tab that is no longer selected. |
| Background error/status text to UI | Returned data is untrusted display content and must not become markup. |
| Side-panel focus to page/runtime | Panel actions must not steal or corrupt page focus. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-03 | Elevation of privilege | status/error renderer | mitigate (blocking) | Enumerated local copy plus `textContent` only; no background-provided HTML or generic markup sink. |
| T-52-04 | Denial of service | switch focus/state | mitigate | Starting stays enabled/focused, page focus is untouched, and focus/state behavior is tested. |
| T-52-06 | Denial of service | unsupported/error presentation | mitigate | Fail-closed unchecked state, exact retryability, and explicit guarantee that no active record/shell is presented. |
| T-52-07 | Spoofing | tab refresh/toggle/status callbacks | mitigate | Capture explicit `_activeTabIdSnapshot`, guard before/after async work, and run out-of-order success/event/rejection tests. |
</threat_model>
