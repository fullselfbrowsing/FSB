```javascript
mountAmbient(preparedToken) {
  // Validate exact prepared token, consume it once, call _choosePlacement()
  // again before createElement/attachShadow/appendChild, and use only the
  // freshly returned placement. Null means false with zero roots/resources.
}

_currentRichGeometry() {
  // For Focused select .skopeo-focused-card; for Interstitial select
  // .skopeo-gate. Return normalized candidate/required-control rectangles.
}

_currentRichGeometryIsSafe() {
  // Delegate current rectangles to _candidateIsSafe().
}

_revalidateGeometry() {
  // Choose a current Ambient placement. If none, request unsafe-layout kill.
  // While Focused/Interstitial is unsafe, call back() synchronously until the
  // nearest suspended measured-safe level is restored; if restoration fails
  // or no safe level exists, request unsafe-layout kill. Apply the new rail/
  // lens placement to Ambient or Anchored without rebuilding identities.
}
```

The resize listener remains the single session-owned listener and calls the synchronous revalidation helper. No polling, observer, server, daemon, dependency, semantic anchor, Graphify engine, or site-specific selector is added.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Root-free prepare to DOM commit | Page controls and viewport geometry are untrusted after any asynchronous prepare/commit gap. |
| Committed rich surface to changing host page | Resize, zoom, or host motion can revoke a once-safe collision certificate. |
| Geometry rollback to suspended scopes | Restoration must not duplicate nodes, resources, focus hooks, or roots. |
| Automated Chrome mechanics to live product evidence | Local deterministic results cannot be represented as Drive/Docs/VoiceOver approval. |
