<interfaces>
Manifest command:

```json
"commands": {
  "toggle-skopeo-current-tab": {
    "suggested_key": {
      "default": "Ctrl+Shift+Space",
      "mac": "Alt+Space"
    },
    "description": "Toggle Skopeo in current tab"
  }
}
```

Extension messages and responses:

```javascript
{ action: 'skopeo:toggle-tab', tabId }
{ action: 'skopeo:get-status', tabId }
{ action: 'skopeo:status-changed', tabId, generation, status, attention?, code?, message? }

{ success: true, tabId, generation, status: 'off'|'starting'|'active', attention?: 'ambient' }
{ success: false, tabId, generation?, status: 'unsupported'|'error', code:
    'SKOPEO_UNSUPPORTED_TAB'|'SKOPEO_START_FAILED'|'SKOPEO_UNSAFE_LAYOUT', message }

// worker -> content runtime
{ action: 'skopeo:prepare', generation }
{ action: 'skopeo:commit', generation }
{ action: 'skopeo:probe', generation }
{ action: 'skopeo:terminate', generation, reason }

// content runtime -> worker; sender.tab.id is authoritative
{ action: 'skopeo:prepared', generation, placement: 'full'|'compact' }
{ action: 'skopeo:ready', generation, attention: 'ambient' }
{ action: 'skopeo:kill-request', generation, reason: 'close'|'escape'|'unsafe-layout'|'navigation' }
{ action: 'skopeo:teardown-complete', generation, reason, resources }

// exact probe response contract
{ success: true, generation, status: 'active', attention: 'ambient', mounted: true }
{ success: false, generation, status: 'stale', code: 'SKOPEO_STALE_GENERATION' }
{ success: false, generation, status: 'missing', code: 'SKOPEO_RUNTIME_MISSING' }
```

The background must derive the tab for content-originated `skopeo:prepared`, `skopeo:ready`, `skopeo:kill-request`, and `skopeo:teardown-complete` from `sender.tab.id`; any tabId in such a payload is ignored/rejected. `skopeo:prepare` may create detached state only. After a matching prepared acknowledgment, the worker persists ACTIVE with allowed record reason `prepared-awaiting-commit`, continues to project Starting publicly, then sends the exact commit. Only matching ready clears that reason and broadcasts/returns Active. Probe never injects, mounts, commits, focuses, renders, or changes attention; message-delivery failure is normalized to the exact missing response.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Side-panel/command request to service worker | Invocation carries a target tab that must remain explicit and stable. |
| Service worker to page runtime | Injection and messages can fail, race navigation, or awaken after MV3 suspension. |
| Page runtime acknowledgment to worker | Payload tab/generation values are untrusted; sender metadata is authoritative. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-01 | Tampering | async prepare/commit/ready/probe/teardown controller | mitigate (blocking) | Keep prepare root-free, persist ACTIVE before exact commit, validate sender/generation at prepared and ready, make probe observational only, persist terminal boundary first, and re-check storage generation plus AbortSignal before every continuation. |
| T-52-03 | Tampering | runtime message dispatcher | mitigate (blocking) | Fixed action/envelope allowlist; no generic render/HTML payload; sender-derived tab identity. |
| T-52-05 | Denial of service | repeated command/injection and missing runtime | mitigate | Per-tab controller, duplicate prepare/commit idempotence, typed missing/stale probe normalization, later explicit reinjection, one dedicated injection list, and one active AbortController. |
| T-52-06 | Denial of service | restricted tab/injection failure | mitigate | URL preflight before STARTING, fail-closed rollback/tombstone, stable unsupported/error responses, no partial active state. |
| T-52-07 | Spoofing | side-panel and content tab routing | mitigate | Explicit side-panel tab ID, command event tab, sender.tab for content acks, and wrong-tab/stale race tests. |
</threat_model>
