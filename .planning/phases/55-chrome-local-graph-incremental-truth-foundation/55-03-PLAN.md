<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Certified Drive text → provider request | Confidential source material can be over-batched, mixed with another source, or treated as instructions. |
| Configured settings snapshot → session/staging/provider | Mid-generation settings drift can mix providers/models across batches or stage output under the wrong provenance. |
| Raw provider response → validated batch | Prose, malformed JSON, unknown fields, references, forged locators, or executable claims can reach staging. |
| Awaited provider result → current source session | Cancellation, revocation, fingerprint change, or session replay can admit delayed stale output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T55-01 | Elevation of privilege / Tampering | prompt and raw response gate | mitigate | Static system policy, JSON-stringified one-source data envelope, no tools/callbacks/URLs, single bare JSON parse, and zero-effect injection fixtures. |
| T55-03 | Information disclosure | excerpt/provider budgets and binding | mitigate | Invariant-only session/staging/batch binding, current-settings recheck before every call/stage, exact configured provider/model spy, 8-excerpt/24,000-character call cap, 8-call/192,000-character generation cap, and raw response confined to the ephemeral certified provider-operation result. Validated labels may contain names, but only the authoritative/lexical/query owners may retain them. |
| T55-04 | Tampering / Denial of service | batch cancellation and certificate choreography | mitigate | Every method consumes one fresh certificate, compares only invariant session fields, and rechecks the current signal before/after await; distinct-operation certificates with matching invariants succeed, reuse/expiry fails, Plan 01 cancellation terminates fetch/backoff, and the effectful provider operation returns through an exact no-storage publisher acknowledgement with zero durable mutation. |
| T55-07 | Tampering | evidence and relation semantics | mitigate | Closed schema plus exact excerpt registry, UTF-8 byte resolution, response-local refs, advertised same-generation prior handles, endpoint matrix, collision/dangling/forward rejection, and no fuzzy/other-source repair. |
| T55-SC | Tampering | framework/package intake | mitigate | Use the existing provider and validator only; no AI framework, eval service, package, Python process, or remote graph component. |
</threat_model>
