<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Source/model object → graph schema | Hostile plain-looking objects can contain accessors, prototypes, unknown keys, oversized values, executable claims, or forged evidence. |
| Identity inputs → stable IDs | Model references, labels, or content fingerprints can accidentally fuse or churn stable source-owned identity. |
| Authority operation → provider fetch/retry | Cancellation can be lost inside fetch timeout composition, backoff sleep, or recursive retry. |
| Upstream Graphify → extension code | An unreviewed runtime or copied fragment would expand the trusted/supply-chain surface. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T55-01 | Tampering / Elevation of privilege | `skopeo-graph-schema.js` | mitigate | Exact descriptors, closed schemas, kind/predicate allowlists, endpoint matrix, no executable fields, and getter-nonexecution tests reject hostile source/model data. |
| T55-02 | Spoofing / Information disclosure | graph ID and candidate-link derivation | mitigate | Length-prefixed exact tuples plus SHA-256 and redundant ownership fields isolate partition/source/kind/locator namespaces; generation-qualified prior handles reject collision/forward/cross-source reuse; cross-document relation versions bind both endpoint versions/generations and canonical proposing-source evidence, while a canonical complete-set digest binds each overlay generation without identity fusion. |
| T55-04 | Denial of service / Tampering | `UniversalProvider` cancellation | mitigate | Link caller abort to the timeout controller, use abortable backoff, remove listeners on settlement, and suppress all retry paths after `FSB_PROVIDER_ABORTED`. |
| T55-09 | Tampering | Graphify/npm/runtime intake | mitigate | No package install or copied code; the pinned conceptual provenance and empty copied-code inventory are enforced by the final static gate. |
| T55-SC | Tampering | npm/package install surface | mitigate | This plan performs no package-manager install and changes no dependency or lockfile. |
</threat_model>
