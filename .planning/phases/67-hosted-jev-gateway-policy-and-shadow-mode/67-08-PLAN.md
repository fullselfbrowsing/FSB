FsbJevClient API (this plan; the Phase 68/70 contract). JSDoc typedefs to include verbatim in the file:
- `JevFallbackReason`: the 19 D-16 strings.
- `JevChoiceDecision`: `{choice:string, confidence:number, probabilities:Object<string,number>, threshold:number|null, meetsThreshold:boolean}`.
- `JevNoulDecision`: `{p:number, threshold:number|null, meetsThreshold:boolean}`.
- `JevOk`: `{ok:true, decisionId, instrumentVersion, servedModel, calibration:{status:'calibrated'|'uncalibrated'|'snapshot_changed', profileId}, decisions:{operation?, target?, completion?, stuck?, risk?}, usage:{inputTokens:number|null, source:'provider'|'unavailable'}, cost:{usd:number|null, source:'provider'|'estimate'|'unavailable'}, latencyMs}` (latencyMs = client-measured end to end).
- `JevFallback`: `{ok:false, fallback:JevFallbackReason, servedModel:string|null, httpStatus:number|null, latencyMs:number}` (httpStatus = the HTTP status the client received from the gateway, null when no response; latencyMs = client-measured).
- Constants: `ENDPOINT = 'https://full-selfbrowsing.com/api/jev/decide'`, `DEFAULT_TIMEOUT_MS = 2500`, `COOLDOWN_MS = 60000`, `MAX_SPEND_COOLDOWN_MS = 3600000`.
- `createJevClient({endpoint = ENDPOINT, fetchImpl, now = () => Date.now(), getHashKey = null, setTimeoutImpl, clearTimeoutImpl} = {})` -> `{decide, resetCooldown}`; fetch resolved lazily at call time (`opts.fetchImpl || globalThis.fetch`), a missing fetch -> network_error.
- `decide(request, {signal, timeoutMs} = {})` -> `Promise<JevOk|JevFallback>`; deadline = min(timeoutMs if a positive finite number, DEFAULT_TIMEOUT_MS).
- Module api: `{ENDPOINT, DEFAULT_TIMEOUT_MS, COOLDOWN_MS, MAX_SPEND_COOLDOWN_MS, createJevClient, decide}` where `decide` belongs to one default instance created at load (no side effects at creation).

Status-only mapping (used only when the body is missing, not JSON, or fails validateGatewayResponse):
| received | fallback |
|---|---|
| 2xx | invalid_response |
| 413 | payload_too_large |
| 429 | rate_limited |
| other 4xx | invalid_request |
| 504 | timeout |
| other 5xx | server_error |
| anything else | invalid_response |
