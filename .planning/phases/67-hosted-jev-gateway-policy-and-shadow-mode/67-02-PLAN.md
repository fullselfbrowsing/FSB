Existing (scripts/bench/lib/stats.mjs, read only):
- `wilson(successes, n, z = 1.959963984540054)` returns `[lower, upper]`, `[NaN, NaN]` when n is 0.
- `mulberry32(seed)` returns a seeded `() => number in [0,1)`.

Harness row format this plan defines (plan 67-12 produces it, this plan consumes it):
`{recordId: string, taskId: string, kind: 'operation'|'target'|'completion'|'stuck'|'risk', label: string|boolean, decision: {choice: string, confidence: number, optionCount: number} | {p: number} | null, fallback: string|null}`
(decision is null exactly when fallback is a D-16 reason string).

Reading format: `{s: number, correct: boolean, positive: boolean, optionCount: number|null, bucketValue: number, acting: boolean}`.
- operation, target: s = confidence; correct = (choice === label); positive = true; bucketValue = confidence; acting = (choice !== 'none_of_the_above').
- completion (veto): s = 1 - p; correct = (label === false) (the veto is right when the task is not done); positive = (label === false); bucketValue = |p - 0.5| x 2; acting = true.
- stuck: s = p; correct = (label === true); positive = (label === true); bucketValue = |p - 0.5| x 2; acting = true.
- risk: s = p; correct = ((p >= 0.5) === label); positive = (label === true); bucketValue = |p - 0.5| x 2; acting = true.

targets.json (exact keys):
`{schemaVersion: 1, note: string, alpha: 0.05, grid: [0.50,0.55,0.60,0.65,0.70,0.75,0.80,0.85,0.90,0.95], tieBand: 0.05, minN: 30, confidenceBuckets: [0,0.5,0.6,0.7,0.8,0.9,0.95,1], optionBands: [[2,3],[4,10],[11,50],[51,255]], kinds: {operation:{mode:'precision',target:0.95}, target:{mode:'precision',target:0.95}, completion:{mode:'precision',target:0.95}, stuck:{mode:'precision',target:0.90}, risk:{mode:'recall',target:0.95}}}`

Selection result per kind: `{status:'fit', cut, effectiveThreshold, n, hits, lower, z}` or `{status:'not_a_fit', effectiveThreshold:null, z, reason:'insufficient_samples'|'no_cut_qualifies'}`.
`toProfileThresholds(selectionByKind)` returns raw-scale thresholds for the server profile (plan 67-03 applies them): operation/target/stuck/risk: threshold = effectiveThreshold (act when confidence or p >= threshold); completion: threshold = 1 - effectiveThreshold (veto when p <= threshold); not_a_fit -> null.
Rounding: every effectiveThreshold (cut + tieBand or cut - tieBand) and every raw profile threshold is rounded to 6 decimal places with `Math.round(x * 1e6) / 1e6`, so 0.80 + 0.05 is exactly 0.85 and 1 - 0.9 is exactly 0.1 (no floating drift between selection and the server's meetsThreshold comparison).
