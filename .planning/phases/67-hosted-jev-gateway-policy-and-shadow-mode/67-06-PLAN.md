FsbJevState API (this plan; consumed by 67-08 client, 67-09 router test, 67-10 records, 67-12 harness, and Phase 68):
- `CONTRACT` (deep-frozen; must deep-equal the server CONTRACT), `isApprovalLikeKey(key)`.
- `scrubText`, `matchesSecret`, `filterInjection`, `luhnValid`, `PATTERN_SOURCES`, `INJECTION_PATTERN_SOURCES`, `PLACEHOLDERS`: behaviourally identical mirrors of scrubber.js.
- `validateRequest(request)` -> `{ok:true}` | `{ok:false, reason:'invalid_request'|'sensitive_goal'}` (identical verdicts to the server validator).
- `validateGatewayResponse(body, request)` -> `{ok:true, value}` | `{ok:false}` where value is a fresh deep copy. Ok shape: exact okResponse keys; decisionId string 1..64; instrumentVersion string 1..64; servedModel string 1..128; calibration exact {status in CALIBRATION_STATUSES, profileId string 1..64}; decisions an object whose key set equals request.kinds exactly; each Choice decision exact choiceDecision keys with choice in its probabilities keys, probabilities keys all in OPERATIONS + RESERVED_OPTION_KEY (operation) or matching ELEMENT_ID_PATTERN + RESERVED_OPTION_KEY (target), every probability and confidence finite in [0,1]; each Noul decision exact noulDecision keys with p finite in [0,1]; threshold null or finite in [0,1]; meetsThreshold boolean, false whenever threshold is null, and false for every decision unless calibration.status is 'calibrated'; usage exact {inputTokens null or non-negative safe integer, source in USAGE_SOURCES} with source 'unavailable' iff inputTokens null; cost exact {usd null or finite >= 0, source in COST_SOURCES} with source 'unavailable' iff usd null; latencyMs finite >= 0. Fallback shape: exact fallbackResponse keys; fallback in GATEWAY_FALLBACK_REASONS; servedModel null or string 1..128; httpStatus null or integer 100..599; latencyMs finite >= 0.
- `buildRequest(input, {byteBudget = BUDGETS.requestByteBudget} = {})` -> `{ok:true, request, idMap, stats}` | `{ok:false, reason:'invalid_request'|'sensitive_goal'}` where:
  - input = `{kinds, goal, url, title, visibleText, elements:[{id, role, label, ops, inputType?, autocomplete?, purpose?:{sensitive?}, hidden?}], vaultFilledIds? (array or Set of caller ids), recentActions?:[{op, targetId, changed}], offeredOps, proposedAction?:{op, targetId}}`
  - idMap: object mapping each emitted Jev id ('e0'...) to the caller's original id (never sent).
  - stats: `{dropped:{sensitive, overCap}, shrink:{textChars, elementsDropped, actionsDropped}, bytes}`.
- `toOriginPath(url)` -> `{origin, path}` for http(s) URLs or null. Query and fragment are dropped. The path is scrubbed one segment at a time: split `URL.pathname` on '/', apply `scrubText` to each segment, and rejoin with '/', so the leading '/' and every separator survive and a 32+ character token segment becomes `[REDACTED_TOKEN]`. Never scrub the whole path string: the high-entropy candidate class includes '/', so a whole-path scrub swallows the leading '/' and the separators, and the server validator then rejects the request; `utf8ByteLength(s)`; `codePointLength(s)`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page DOM snapshot -> request | Untrusted page content and possibly sensitive form state |
| extension -> FSB gateway (HTTPS) | Everything in the request leaves the machine |
| gateway response -> extension | Response is untrusted until exact-key validated |
