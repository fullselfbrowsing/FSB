Fixture pages live in `scripts/bench/fixtures/<slug>/` and task definitions in `scripts/bench/tasks/core/core-<category>-<slug>.json`.

Record format (this plan; plan 67-12 consumes it), exact keys:
`{schemaVersion: 1, id: 'shadow-<slug>-<nn>', provenance: 'hand'|'recorded-llm'|'code-outcome', task: {id, version, fixtureSha256}, step: integer >= 0, request: <request v1>, labels: {operation, target, completion, stuck, risk}, note: string (<= 300 chars)}`
- request: a v1 request that passes `validateRequest` on both sides; origin `http://127.0.0.1:4173` (stand-in for the loopback fixture server) and path `/fixtures/<slug>/<file>` (no query string); element ids e0..eN; labels taken from the fixture page's visible text.
- labels: each key present; value null when that kind is not in request.kinds; otherwise operation is a member of request.offeredOps or 'none_of_the_above', target is a request element id or 'none_of_the_above', completion/stuck/risk are booleans.
- File name must equal `<id>.json`.

records.mjs API: `RECORD_SCHEMA_VERSION = 1`, `PROVENANCES = ['hand','recorded-llm','code-outcome']`, `SHADOW_RECORDS_ROOT` (absolute path of `scripts/bench/shadow/records`), `validateRecord(record)` -> `{ok, errors}` (collects every error; checks exact keys, the label rules above, both request validators via `createRequire(import.meta.url)` loading `../../../../showcase/server/src/jev/validator.js` and `../../../../extension/ai/jev-state.js`), `loadRecords({recordsRoot = SHADOW_RECORDS_ROOT} = {})` -> sorted, deep-frozen records (throws one aggregated Error listing every invalid file, including a file-name mismatch), `checkLockReferences(records, lock)` -> `{ok, errors}` comparing each record.task with the lock entry.
</interfaces>
