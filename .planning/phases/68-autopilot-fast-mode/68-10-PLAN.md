Copy facts (only these; D-07 copy accuracy):
- Scope (sync issue 1): the sent and never-sent lists describe only what fast mode sends to FSB's server (and, through it, to TypeSafe AI or OpenRouter). Fast mode does not change what FSB sends to the AI provider the user chose (External Services): that provider still plans, types and reads, and after fast steps it gets the same kind of page description it gets with fast mode off. FSB's own page descriptions for that provider include the contents of form fields (extension/content/dom-analysis.js formatInlineRef :2213-2217), so the copy must never say that FSB never reads, sees or sends what the user typed; write "fast mode leaves out ..." and "never sent to FSB's server" instead.
- Sent to FSB's server per fast-mode step: the user's task text; the page origin and path (no query string or fragment); the page title; a short excerpt of visible text (fast mode leaves out form fields and editable text); the labels and roles of visible buttons, links and fields; a short record of recent simple actions (kind of action, which listed control, whether the page changed).
- Never sent to FSB's server: anything typed into fields or any field value; passwords, payment, hidden and file fields, and fields FSB filled from saved credentials or payment methods; URL query strings and fragments; cookies, API keys and credentials. Secrets matching FSB's patterns are removed from text first; if the task text itself holds such a secret, nothing is sent for that task.
- Recipients: FSB's server at full-selfbrowsing.com, which asks TypeSafe AI's Jev model for the decision either directly or through OpenRouter (the route is fixed at V2 and checked at V6, M-68-10). The extension never contacts TypeSafe or OpenRouter for this feature and holds no Jev or OpenRouter key.
- FSB keeps (67 D-24): a per-decision record without any request content for 7 days (time, model version, calibration status, element count, request size, token counts, cost, latency, outcome) and daily totals for 365 days; never the task text, page address, title, page text, control labels, install hash key or IP address.
- TypeSafe (External Research 2): states it does not train or fine-tune models on these inputs and hosts its service in the United States; it keeps data as long as reasonably necessary to provide its services, per its privacy policy. Never claim TypeSafe does not retain requests. If OpenRouter is the route, FSB keeps OpenRouter prompt logging off for its account (verified at V2, M-67-07).
- Control: off by default; in Advanced Settings; can be turned off at any time (nothing is sent while off); an MCP client connected to FSB can also change it through FSB's settings tool; experimental, and until FSB has calibrated it fast mode acts on nothing, though a task may send one step description before it stops asking.
- Limited Use (Chrome Web Store User Data Policy; sync issue 3): the statement opens with the affirmative compliance sentence "FSB's use of information received through fast mode complies with the Chrome Web Store User Data Policy, including the Limited Use requirements." It then says that this information is used only to choose simple steps for the task the user started, is transferred to TypeSafe AI (directly or through OpenRouter) only to provide that feature, is never sold, never used for advertising or creditworthiness, and is not read by people except as the policy allows.
