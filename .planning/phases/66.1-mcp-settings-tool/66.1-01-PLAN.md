Instance API (returned by create(entries)). Every instance, fixture instances included, also carries all the statics (create included), so a test can assign a fixture instance to globalThis.FsbSettingsSchema and every consumer (dispatcher, panel sync) keeps working; the production api is simply create(PRODUCTION_ENTRIES), frozen:
- `entries` (frozen), `keys()` (array in entry order), `get(key)` (entry or null; null for any non-string or non-KEY_PATTERN input), `isWritable(key)`, `readOnlyKeys()` (secret + endpoint keys in entry order)
- `effectiveDefault(key, ctx)`: the entry default; for `{from:'agentCapRecommendation'}` returns `ctx.agentCapRecommendation` when it is a finite integer in 1..64, else 8
- `projectValue(key, stored, ctx)`: "stored" means `Object.prototype.hasOwnProperty.call(stored, key) && stored[key] !== undefined`. secret -> '[set]' when the stored value is a non-empty string after trim, else ''. endpoint -> originOnly(stored value, or the effective default when absent). other -> the stored value as-is, else effectiveDefault.
- `projectAll(stored, ctx)` -> `{ settings: { <key>: projected, ... in entry order }, readOnly: readOnlyKeys() }`
- `describe(key, stored, ctx)` -> `{ key, value: projectValue(...), type, writable, range?: { min, max } (integer), values?: [...] (enum) }`
- `parseValue(key, raw)` -> `{ ok: true, value }` or a failure object

Failure object (parse and plan): `{ ok: false, code, error, key: safeKeyLabel(key), range?, values? }`. `error` is a value-free sentence (it may name the key only via safeKeyLabel and the bounds or allowed values; never the raw input).

Parse rules (D-04, D-14): raw must be a string of length <= VALUE_MAX_LENGTH, else REQUEST_INVALID (non-string) or VALUE_INVALID (too long). boolean: exactly 'true' or 'false'. integer: /^[0-9]{1,6}$/ then Number, must be inside min..max (never clamped). enum: exact member. string: raw.trim(), length <= entry.maxLength. Errors: VALUE_INVALID with `range` (integer) or `values` (enum).

originOnly(raw) (D-11): '' for a non-string or empty string; `new URL(raw)` in try/catch -> '[set]' on throw; '[set]' when `origin` is missing or 'null'; else `origin` plus '/...' when pathname is not '' or '/', or search or hash is non-empty. Userinfo is dropped by construction.

safeKeyLabel(key): the key when it is a string matching KEY_PATTERN, else '[invalid]'.
