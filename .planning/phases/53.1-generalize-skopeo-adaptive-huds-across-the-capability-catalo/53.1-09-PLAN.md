<interfaces>
Plan 09 extends the Plan 08 authority module with:

```text
analyzeArgumentSchema(resolvedEntry, executionAuthority) -> {
  mode: "empty" | "form" | "unsupported",
  fields: [
    {
      name, label,
      kind: "string" | "boolean" | "integer" | "number" | "choice",
      required,
      choices, minLength, maxLength, minimum, maximum
    }
  ],
  reason: null | CLOSED_REASON,
  schemaDigest
}

parseCollectedArguments(argumentContract, submittedOwnKeyObject) ->
  { ok: true, args: DEEP_FROZEN_TYPED_OBJECT } |
  { ok: false, reason: CLOSED_REASON }

validateCollectedArguments(argumentContract, args) -> boolean
```

All field records use the exact keys above; non-applicable constraints are `null`, not omitted. `fields` is empty for `empty` and `unsupported`. No record may contain `default`, `examples`, `value`, `placeholder`, schema description, or page-derived text.

The runtime action sequence is:

```text
Ready row selected
  -> mode=empty: bind `{}` to current tuple and dispatch
  -> mode=form: render one blank Focused form
       -> `submit-arguments` with raw own-key values
       -> parse exact fields into typed args
       -> withdraw form and dispatch
  -> mode=unsupported: no control/event/dispatch
```

Plan 09 wires both `invokeSelectedRead(row,args)` and `openSelectedConsequence(row,args)`, but generated writes remain static until Plan 10 adds `consequenceCompatible:true`.
