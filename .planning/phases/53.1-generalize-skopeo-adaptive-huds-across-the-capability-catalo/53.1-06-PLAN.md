<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Content gate request → background manager | Content-provided slug/args/tuple are untrusted; display target/effect/risk/parameter copy is derived from the current projection, verified semantic context, descriptor schema, and validated args, and a generic page noun is never target authority. |
| User confirmation → router invoke | Confirmation is one-shot and must revalidate all authority immediately before the call. |
| Router result → content result renderer | Typed result may return only to the same live tuple and is rendered later as bounded data. |
