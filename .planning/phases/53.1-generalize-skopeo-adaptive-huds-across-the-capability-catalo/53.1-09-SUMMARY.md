## Accomplishments

- Extended installed action authority with a closed schema analyzer, raw-value parser, and canonical typed-argument validator. Empty-object validity is tested against the complete router schema before field counts, preserving real `zillow.search_for_sale` as runnable with its 13 optional properties and 12-name display summary.
- Compiled root-object schemas into at most 12 deterministic string, boolean, integer, finite-number, or scalar-choice fields. Required arrays, objects, references, combinators, conditionals, unsafe patterns, excessive required fields, and secret material produce a static unsupported contract; optional unsafe fields are omitted and remain unaccepted.
- Regenerated the full catalog with `argumentContract` and `actionabilityReason`: 1,285 source-Ready capabilities become 1,259 runnable Ready reads plus 26 accurate static rows. The 749 required-argument cases remain exactly 744 reads and five writes, and every write stays static pending a trusted consequence contract.
- Added one native form inside the existing Focused Shadow shell. All controls start blank or unchecked, choices begin on a disabled empty option, labels are programmatic, parser errors focus the corresponding field, Escape cancels, repeat submission is consumed synchronously, and route/kill disposal clears values and returns listeners/resources to exact zero.
- Replaced hard-coded selection arguments with a tuple-owned runtime sequence. Empty contracts dispatch a fresh frozen object; form contracts retain only authority, contract, and collection epoch; successful parsing withdraws the form before choosing exactly one read or future consequence path.
- Hardened the background read boundary to derive tab authority from the sender, require the current projected and generated Ready row, bind the request digest, re-resolve the installed handler, compare complete normalized authority, recompute the collector contract, validate typed args against both collector and full installed schema, and invoke only `FsbCapabilityRouter.invoke`.

## Decisions Made

- Validate `{}` with the exact full installed schema before considering how many optional properties exist. Display truncation is never execution authority, so Zillow remains a valid empty-contract read.
- Prefer required fields, then include safe optional scalar fields only within the 12-field ceiling. Optional excluded fields are not accepted later because collector validation requires exact known keys.
- Derive labels only from safe property names. Do not project schema titles, descriptions, defaults, examples, representative values, or arbitrary regexes; do not render secret-shaped or secret-annotated fields.
- Keep consequence-bearing source-Ready rows static until Plan 10 supplies exact trusted target/effect/material compatibility. Plan 09 threads typed arguments to the future consequence seam without enabling it.
- Treat content claims as non-authoritative. The background must match the stored tuple and projection, generated complete authority, and newly resolved installed authority before token consumption and router invocation.
