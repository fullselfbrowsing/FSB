<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Graph/candidate set → family membership | Candidate relations, labels, dates, insertion order, and similar names may appear persuasive but only explicit endpoint-current cited lineage can join/sequence instruments. |
| Execution/effect evidence → four lineage axes | Missing evidence can be mistaken for unsigned, later dates can be mistaken for effective/governing, and a single combined status can hide uncertainty. |
| Partial amendment → clause applicability | An unclear or broad target can silently overwrite unrelated base clauses or allow unorderable overlays to win. |
| Applicable assertions/rules → conflict/deadline clearance | Confidence, majority, recency, hidden date defaults, or collapsed conflicts can create a false cleared/eligible deadline. |
