<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Adjudicator snapshot → durable truth pages | A caller can forge IDs/hashes, omit input versions, exceed caps, or stage partial/conflicting pages unless the complete truth-schema snapshot is reparsed. |
| Immutable pages → reader visibility | Presence, timestamp, storage order, or an abandoned staging journal must never make truth active; only one validated family control pointer grants visibility. |
| Source/graph mutation → multi-source family | Withdrawing only the changed source's local rows can leave a family pointer or sibling reverse dependency that still exposes stale governing truth. |
| Corpus participant capability → truth purge | A cloned/replayed/wrong-mode capability or uncertain absence proof can falsely report citations removed while assertions/deadlines remain reachable. |
| MV3 restart/corruption → recovery | Recovery can select a newest page, reconstruct authority, or expose asymmetric dependencies if it is not sorted, capped, and fail closed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T56-07 | Tampering / Repudiation | truth store publication/dependencies | mitigate in Tasks 1-3 | Pointer-first withdrawal, journaled immutable pages, symmetric dependencies, pointer-last publish, exact hashes, absence proof, fault matrix, and bounded recovery. |
| T56-05 | Spoofing | complete input binding | mitigate in Tasks 1-2 | Reparse all source/fragment/record/relation/candidate/rule versions and reject partial/max-prefix snapshots before any active pointer. |
| T56-03 | Tampering | citations participant | mitigate in Tasks 1-3 | Real participant owns every Phase 56 influence, authenticates exact one-call corpus capability before/after awaits, and returns owned true on uncertainty. |
| T56-06 | Tampering | conflict/deadline page reachability | mitigate in Tasks 2-3 | Pages are visible only through the exact active snapshot; source/overlay change clears the family pointer before graph publication. |
| T56-08 | Information disclosure | storage/diagnostics | mitigate in Task 3 | No raw source/provider data, URLs, filenames, graph labels, fact/date/address values, or raw errors in diagnostics; no raw key/store API crosses the facade. |
</threat_model>
