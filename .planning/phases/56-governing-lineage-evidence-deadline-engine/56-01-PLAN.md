## Trust Boundaries

| Boundary | Description |
|---|---|
| Source/model-shaped object → truth schema | Page/model data may use prototypes, accessors, symbols, unknown fields, forged IDs, executable expressions, over-cap arrays, or misleading confidence/governing fields. |
| Graph evidence tuple → truth citation | A locator can be clipped, cross-source, stale, or rebound to a different record/relation generation unless every component participates in local identity derivation. |
| Typed assertion/conflict → downstream clearance | A permissive value bag or confidence threshold could collapse unlike facts or erase competing applicable evidence. |
| Contract rule → civil-date arithmetic | Locale parsing, implicit UTC, dynamic dispatch, hidden calendars, or unsupported boundary semantics can produce a plausible but incorrect deadline. |
