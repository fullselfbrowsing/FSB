<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| content → background message | Host-page-adjacent content code submits untrusted action names, keys, tokens, and timing. |
| background → Drive transport | Authenticated metadata and access checks cross into an external provider and may change during an operation. |
| background → content projection | Trusted manifest/graph/truth state is minimized before entering the page-adjacent renderer. |
| content action → new browser tab | An opaque click requests a privileged navigation whose URL must be freshly derived in background. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-57-01 | Spoofing | HUD messages | mitigate | Exact-key validation, sender-derived tab/controller identity, and current explicit-invocation tokens reject caller-supplied authority. |
| T-57-02 | Tampering | Projection tuple and source set | mitigate | `runSkopeoCorpusOperation` plus post-await tuple/entity/source/truth rechecks withdraw stale work before publication. |
| T-57-03 | Information Disclosure | Content projection | mitigate | Schema caps and forbidden-key tests exclude raw IDs, URLs, page content, locators, account data, and store handles. |
| T-57-04 | Elevation of Privilege | Citation open | mitigate | One-shot projection-bound IDs, ready→pending atomic transition, fresh access/revision checks, and guarded commit precede `chrome.tabs.create`. |
| T-57-05 | Repudiation | Action lifecycle | mitigate | Deterministic diagnostic reason codes record issue, revoke, reject, and consume transitions without logging sensitive identifiers. |
| T-57-06 | Denial of Service | Folder projection | mitigate | Frozen caps, exact source sets, bounded label resolution, and controller-local replacement prevent unbounded joins or retained work. |
| T-57-08 | Tampering | Controller teardown | mitigate | Hide, navigation, replacement, and lifecycle teardown revoke projection/action epochs before subsequent render authority. |
| T-57-SC | Tampering | npm/pip/cargo installs | mitigate | No package installation occurs in this plan; existing lockfiles and dependency set remain unchanged. |
</threat_model>
